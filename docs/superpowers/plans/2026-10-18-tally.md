# Tally Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Il server legge program/preview/nomi/fade-to-black da un Blackmagic ATEM e ogni telefono Android con un ingresso assegnato mostra una fascia tally in alto; in più la disconnessione dal server si rileva in 2–3 s.

**Architecture:** Nuovo pacchetto Go `server/internal/tally` con: codec del protocollo ATEM UDP 9910, client con riconnessione, finto ATEM per test e prove a mano, e una funzione pura che calcola lo stato tally per un utente. L'hub tiene l'ultimo snapshot e invia a ogni sessione un messaggio WebSocket `tally` già pronto (`state` + `text`), solo quando cambia. Lato client `shared/` decodifica il messaggio e decide la fascia (inclusa `DISCONNESSO`); Android la disegna.

**Tech Stack:** Go stdlib (`net`, `encoding/binary`), pagina admin HTML/JS senza framework, Kotlin `shared/` (org.json, JUnit), Jetpack Compose.

**Spec:** `docs/superpowers/specs/2026-10-18-tally-design.md`

## Global Constraints

- Testi visibili in **italiano**; codice, commenti, commit in **inglese**; commit `feat(server): ...`, `feat(android): ...`, `feat(shared): ...`, `docs: ...`.
- Nessuna nuova dipendenza: ATEM solo con stdlib Go.
- Protocollo condiviso: ogni cambio in `server/internal/proto/proto.go` va anche in `shared/src/main/kotlin/app/intercom/core/proto/Messages.kt` e `docs/protocollo.md`, nello stesso commit.
- Se cambia un comportamento descritto in `docs/`, aggiornare il documento nello stesso commit.
- Scorciatoie volute marcate con commento `ponytail:`.
- Testi esatti: `● IN ONDA`, `PREVIEW`, `IN ONDA: <nome>`, `IN ONDA: <nome> <utente>`, `IN ONDA: <A> + <B>`, `NERO · nessuno in onda`, `TALLY NON DISPONIBILE`, `DISCONNESSO`.
- Porta ATEM fissa UDP **9910**. Un solo M/E (indice 0).
- Il pulsante PARLA **non** cambia (resta "IN ONDA" quando premuto).
- Fascia: altezza fissa 44 dp, una riga, troncata con "…".

## Review Focus

1. **Pacchetto ATEM troncato o con comando di lunghezza assurda** → il server ignora il resto senza panic. Test `TestApplyIgnoresTruncatedCommands` (Task 2).
2. **Assegnazione tolta, utente disabilitato o tally disattivato con telefoni connessi** → la fascia sparisce subito (`state: "off"`). Test `TestTallyOffWhenUnassignedOrDisabled` (Task 4).
3. **ATEM che smette di rispondere (cavo staccato)** → entro ~5 s tutti gli assegnati ricevono `unavailable`; al ritorno lo stato si ripristina. Test `TestClientDetectsSilenceAndReconnects` (Task 3).
4. **Telefono che si riconnette** → riceve subito lo stato attuale, non quello vecchio. Test `TestLoginSendsCurrentTally` (Task 4).
5. **IP cambiato dall'admin mentre è connesso** → il vecchio collegamento si chiude, mai due loop insieme. Test `TestConfigureSwitchesHost` (Task 3).

### Task 2: Codec del protocollo ATEM

**Files:**
- Create: `server/internal/tally/atem.go`
- Test: `server/internal/tally/atem_test.go`

**Interfaces:**
- Consumes: `Snapshot`, `Input` (Task 1).
- Produces (non esportati, usati da Task 3):
  - flag: `flagAckRequest=0x01`, `flagHello=0x02` (NewSessionId), `flagRetransmit=0x04`, `flagRetransmitRequest=0x08`, `flagAck=0x10`.
  - `type header struct{ flags uint8; length int; session, ackID, remoteID uint16 }`
  - `func parseHeader(b []byte) (header, bool)` — `u16@0 = flags<<11 | length` (11 bit), session `@2`, ackID `@4`, remoteID `@10`; false se `len<12` o `length>len(b)`.
  - `func helloPacket(session uint16) []byte` — 20 byte: header flags=hello, length 20, session, byte 9 = `0x3a`, payload `01 00 00 00 00 00 00 00`.
  - `func ackPacket(session, id uint16) []byte` — 12 byte, flags=ack, ackID=id.
  - `func packet(flags uint8, session, remoteID uint16, payload []byte) []byte` (usato dal finto ATEM).
  - `func command(name string, data []byte) []byte` — `u16 len (8+len(data)) | u16 0 | 4 byte nome | data`.
  - `func (s *Snapshot) apply(payload []byte) (initDone bool)` — scorre i comandi; `initDone` true se contiene `InCm`.
- Layout dei comandi (byte dopo gli 8 di intestazione):
  - `_pin`: nome modello, 40 byte, terminato da NUL.
  - `InPr`: `u16 id @0`, nome lungo 20 byte `@2`, `internalPortType u8 @32` (0 = esterno). Aggiorna o aggiunge per id, ordine di arrivo.
  - `TlSr`: `u16 n @0`, poi n × (`u16 sourceId`, `u8 flags`): bit0 program, bit1 preview. Sostituisce `Program`/`Preview`, ordinati.
  - `PrgI`: `u8 me @0`, `u16 source @2` → `ProgramSource` solo se me==0.
  - `FtbS`: `u8 me @0`, `u8 fullyBlack @1`, `u8 inTransition @2` → `Black = fullyBlack && !inTransition` solo se me==0.

- [ ] **Step 1: Write the failing tests**
  - `TestParseHeader`: hello reply `{0x10,0x14,0x53,0xab,0,0,0,0,0,0x3a,0,0,…}` → flags 0x02, length 20, session 0x53ab.
  - `TestHelloAndAckBytes`: `helloPacket(0x53ab)` uguale ai 20 byte sopra con byte 12 = 0x01; `ackPacket(0x8001, 7)` = `{0x80,0x0c,0x80,0x01,0x00,0x07,0,0,0,0,0,0}`.
  - `TestApplyCommands`: payload scritto a mano byte per byte (non con `command`) con `_pin "ATEM Production Studio 4K"`, `InPr` id 1 "CAM 1" esterno e id 3010 "MP1" con internalPortType 4, `TlSr` n=2 {(1, 0x01), (2, 0x02)}, `PrgI` me 0 source 1, `FtbS` me 0 fullyBlack 1 inTransition 1, `InCm` → Model, Inputs, Program [1], Preview [2], ProgramSource 1, `Black == false` (dissolvenza in corso), `initDone == true`.
  - `TestApplyIgnoresTruncatedCommands`: payload con comando valido seguito da intestazione con length 500 / length < 8 / 3 byte avanzati → nessun panic, il comando valido è applicato.

### Task 3: Client ATEM con riconnessione e finto ATEM

**Files:**
- Create: `server/internal/tally/client.go`, `server/internal/tally/fake.go`, `server/cmd/fakeatem/main.go`
- Test: `server/internal/tally/client_test.go`

**Interfaces:**
- Consumes: codec di Task 2.
- Produces:
  - `type Client struct{ OnChange func(Snapshot); Port int /* 0 = 9910 */; Silence time.Duration /* 0 = 5s */ }`
  - `func (c *Client) Configure(enabled bool, host string)` — ferma il loop precedente e aspetta che sia uscito, poi ne avvia uno nuovo se `enabled && host != ""`; altrimenti pubblica `Snapshot{}`.
  - `func (c *Client) Snapshot() Snapshot` (copia).
  - `type FakeATEM`, `func NewFakeATEM(addr string) (*FakeATEM, error)`, `func (f *FakeATEM) Port() int`, `func (f *FakeATEM) Set(fn func(*Snapshot))`, `func (f *FakeATEM) Close()`.
- Loop: socket UDP verso `host:port`; invia `helloPacket` con session casuale; per ogni pacchetto ricevuto adotta `session` dall'header; se flag hello → `ackPacket(session, 0)`; se `flagAckRequest` → `ackPacket(session, remoteID)`; payload → `apply`. `Connected = true` solo dopo `InCm`. Ogni cambio dello snapshot (confronto con `reflect.DeepEqual`) → `OnChange`, chiamato fuori da ogni lock del client. Nessun pacchetto per `Silence` → `Snapshot{}` (non connesso) pubblicato, nuovo hello dopo 1 s.
- `ponytail:` niente gestione delle ritrasmissioni (riordino/perdita su LAN rara; il prossimo `TlSr` corregge).
- Finto ATEM: risponde all'hello con flag hello; poi invia come pacchetti reliable `_pin`, ogni `InPr`, `PrgI`, `TlSr`, `FtbS`, `InCm`; ping reliable vuoto ogni 500 ms; `Set` modifica lo stato e invia `TlSr`, `PrgI`, `FtbS` aggiornati. Stato iniziale: `ATEM Production Studio 4K`, ingressi 1–8 `CAM 1`…`CAM 8` esterni, `3010 MP1` non esterno, program 1, preview 2.
- `cmd/fakeatem`: flag `-addr` (default `:9910`); legge righe da stdin: `pgm N`, `pvw N`, `mix A B` (entrambi in program), `ftb` (alterna nero), `quit`. Messaggi in italiano.
